# 02 — The Bias-Variance Trade-off

The expected test Mean Squared Error (MSE) of a supervised learning model decomposes into three irreducible quantities:

<FormulaCard
  title="Bias-Variance Decomposition"
  formula="\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \mathrm{Bias}\left[\hat{f}(x)\right]^2 + \mathrm{Var}\left[\hat{f}(x)\right] + \sigma^2"
  variables={[
    { symbol: "\\mathrm{Bias}[\\hat{f}(x)]^2", description: "Error introduced by approximating a complicated real-world problem with a simpler model" },
    { symbol: "\\mathrm{Var}[\\hat{f}(x)]", description: "Amount by which the model estimate would change if estimated using a different training set" },
    { symbol: "\\sigma^2", description: "Irreducible random error inherent in the true data generating process" }
  ]}
  explanation="As model complexity increases, bias declines while variance increases. Regularization techniques penalize extreme model coefficients to strike the optimal bias-variance balance."
/>

# 03 — Regularized Regression: Ridge, Lasso & Elastic Net

<ComparisonCard
  title="L1 vs L2 Regularization Dynamics"
  labelA="Ridge Regression (L2 Penalty: lambda * sum(beta_j^2))"
  labelB="Lasso Regression (L1 Penalty: lambda * sum(|beta_j|))"
  featureA="Shrinks coefficients smoothly toward zero but never forces them to exact zero. Retains all predictors in the final model; well-suited when many predictors have small, non-zero effects."
  featureB="Enforces sparsity by driving coefficients to exact zero when penalty lambda is sufficiently large. Performs automated feature selection; well-suited for high-dimensional sparse data."
/>
