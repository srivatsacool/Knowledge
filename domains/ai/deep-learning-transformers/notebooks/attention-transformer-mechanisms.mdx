# 02 — Scaled Dot-Product Attention

Given an input matrix of Query vectors $Q$, Key vectors $K$, and Value vectors $V$ of dimension $d_k$:

<FormulaCard
  title="Scaled Dot-Product Attention Equation"
  formula="\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V"
  variables={[
    { symbol: "Q \\in \\mathbb{R}^{n \\times d_k}", description: "Matrix of query vectors representing tokens seeking context" },
    { symbol: "K \\in \\mathbb{R}^{m \\times d_k}", description: "Matrix of key vectors representing tokens offering context" },
    { symbol: "V \\in \\mathbb{R}^{m \\times d_v}", description: "Matrix of value vectors containing the token representation payloads" },
    { symbol: "\\sqrt{d_k}", description: "Scaling factor to prevent dot products from growing excessively large for large dimensions, which would push softmax into near-zero gradient regions" }
  ]}
  explanation="The inner product Q K^T measures semantic affinity between token pairs. Softmax normalizes affinities into a probability distribution over keys, weighting the linear combination of values V."
/>

# 03 — Multi-Head Attention (MHA)

Rather than performing a single attention function with `$d_{model}$`-dimensional queries, keys, and values, Multi-Head Attention projects $Q, K, V$ linearly $h$ times with different learned parameter matrices:

<FormulaCard
  title="Multi-Head Attention (MHA) Formulation"
  formula="\mathrm{MultiHead}(Q, K, V) = \mathrm{Concat}(\mathrm{head}_1, \dots, \mathrm{head}_h) W^O, \quad \text{where } \mathrm{head}_i = \mathrm{Attention}(Q W_i^Q, K W_i^K, V W_i^V)"
  explanation="Projects queries, keys, and values h times with distinct parameter projections, enabling the model to attend to multiple representation subspaces simultaneously."
/>

* Allows the model to jointly attend to information from different representation subspaces (e.g., one head tracking syntactic subject-verb dependencies, another tracking coreference resolution).
